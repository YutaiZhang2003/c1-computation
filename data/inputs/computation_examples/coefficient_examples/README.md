# Liouville coefficient table examples

These 11 small CSV tables contain 1,453 coefficient rows. Each has a JSON file with momenta, weights, expansion variables, truncation, precision, excluded factors and an example evaluated value.

| --- | --- | ---: |

These are retained reference examples, with parameters and generation receipts beside the tables. They illustrate block conventions and are not complete production coefficient banks. Historical exporter commands in the receipts refer to the original source packages.
